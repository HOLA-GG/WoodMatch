# Manual de usuario

WoodMatch ayuda a registrar, ofrecer y aprovechar madera y residuos leñosos dentro de Suba, Bogotá. Este manual explica el uso de la aplicación; las recomendaciones botánicas y de evidencia son orientativas y siempre deben revisarse.

## 1. Crear una cuenta

1. En la pantalla de acceso, pulsa **Crear cuenta**.
2. Completa nombre, correo, teléfono, ubicación y contraseña.
3. Elige el rol que describe tu actividad:
   - **Generador:** tienes material que puedes entregar.
   - **Receptor:** buscas material para aprovechar.
   - **Mixto:** puedes ofrecer y buscar.
4. Lee y acepta el aviso de privacidad.
5. Pulsa **Registrarme** e inicia sesión.

El rol se selecciona durante el registro y no se cambia desde el perfil normal. Si necesitas ambas acciones, usa una cuenta Mixta.

## 2. Iniciar sesión

1. Escribe tu correo y contraseña.
2. Pulsa **Ingresar**.
3. Si la aplicación muestra un error de red, revisa Internet y vuelve a intentarlo.

No compartas tu contraseña ni códigos de retiro.

## 3. Crear un reporte

Los receptores pueden registrar un **hallazgo**. Generadores y mixtos también pueden crear una **oferta** de material que estén autorizados a entregar.

1. Desde Inicio, pulsa el botón principal **Crear** o **+**.
2. Selecciona **Reportar hallazgo** u **Ofrecer material**.
3. Adjunta una foto desde la cámara o galería. La foto es obligatoria como evidencia.
4. Pulsa **Usar mi ubicación** y concede el permiso si quieres usar GPS. Si no funciona, selecciona el punto directamente en el mapa.
5. Confirma que el punto está en el área de atención de Suba.
6. Opcionalmente pulsa **Sugerir datos desde la evidencia**. Revisa la propuesta y pulsa **Aplicar al formulario** solo si los datos son correctos.
7. También puedes pulsar **Orientación para este reporte** para recibir una guía breve.
8. Completa título, material, condición, cantidad y descripción. Para una oferta indica una cantidad mayor a cero.
9. Revisa el resumen, confirma el consentimiento de ubicación y, para una oferta, la autorización para entregar.
10. Pulsa **Publicar**.

### Borrador

Al salir puedes elegir:

- **Guardar y salir:** conserva el avance para tu cuenta.
- **Descartar y cerrar:** elimina ese borrador.
- **Continuar editando:** vuelve al formulario.

Después de publicar, un reporte nuevo comienza vacío.

## 4. Consultar el mapa

1. Pulsa **Mapa** en la navegación inferior o desde Inicio.
2. Mueve el mapa, acerca o aleja para explorar publicaciones.
3. Usa los filtros cuando necesites limitar los resultados.
4. Toca un marcador o tarjeta para abrir el detalle.

El mapa muestra puntos aproximados para consulta. No compartas ni uses una ubicación para visitar una propiedad sin coordinar previamente con la persona responsable.

## 5. Buscar, reservar y retirar material

Disponible para receptores y mixtos:

1. En Inicio pulsa **Buscar**, o abre el Catálogo/Mapa.
2. Abre una oferta disponible y revisa foto, descripción, condición y ubicación.
3. Pulsa **Solicitar** y completa uso previsto, fecha propuesta, cantidad y mensaje.
4. Espera la respuesta de quien ofrece el material.
5. Si acepta, entra a **Mi actividad** y usa **Emitir pase**.
6. Muestra el QR o código de retiro a la persona que entrega. El pase tiene duración limitada.
7. La persona oferente valida el pase.
8. Después de la entrega física, ambas personas confirman la entrega desde sus actividades.
9. Al confirmarla ambas partes, aparece el comprobante.

Puedes cancelar una solicitud activa. Si ya estaba aceptada, la reserva se libera cuando el flujo lo permite.

## 6. Revisar Mi actividad

En **Mi actividad** encuentras:

- Tus hallazgos y ofertas.
- Solicitudes recibidas y enviadas.
- Estado de reserva y entrega.
- Pase de retiro y comprobante cuando corresponda.

Una oferta reservada no se puede editar. Revisa cuidadosamente antes de aceptar, cancelar o confirmar una entrega.

## 7. Usar la guía botánica

1. Abre **Guía botánica** desde Inicio.
2. Busca por nombre o usa los filtros desplegables de región, categoría y temporada.
3. Para identificar una planta, adjunta una foto en el escáner.
4. Revisa la coincidencia de Pl@ntNet como orientación, no como identificación definitiva.
5. Si está disponible, pide orientación sobre apariencia, cuidados, tallo o corteza.

No uses esta guía para determinar seguridad, toxicidad, permisos de tala ni resistencia de madera.

## 8. Ajustes y accesibilidad

En **Ajustes** puedes:

- Elegir tema claro u oscuro.
- Elegir una estación visual.
- Cambiar el tamaño de letra.
- Abrir información, privacidad y contacto.

Si tienes dificultades de lectura, aumenta la letra desde la app y desde los ajustes de accesibilidad de Android.

## 9. Editar perfil y recuperar contraseña

### Perfil

Desde **Perfil** puedes actualizar datos permitidos como nombre y teléfono. También tienes opciones para exportar o solicitar eliminación de tu cuenta.

### Recuperar contraseña

1. En la pantalla de acceso pulsa **¿Olvidaste tu contraseña?**
2. Escribe el correo de la cuenta.
3. Revisa la bandeja de entrada y correo no deseado.
4. Sigue el enlace recibido y vuelve a iniciar sesión.

Por seguridad, la aplicación no confirma públicamente si un correo existe o no.

## 10. Enviar feedback

Cuando el módulo de feedback esté disponible:

1. Abre **Feedback** desde Ajustes o el menú indicado.
2. Elige una categoría: error, sugerencia, accesibilidad, contenido o seguridad.
3. Describe qué ocurrió, qué esperabas y los pasos para repetirlo.
4. Adjunta una captura solo si no contiene contraseñas, códigos, ubicación exacta de terceros ni información privada.
5. Envía el reporte y revisa su estado en la misma sección si la versión lo permite.

Para un cierre inesperado, también puedes capturar un registro técnico desde el computador con ADB y retirar cualquier dato personal antes de compartirlo.
