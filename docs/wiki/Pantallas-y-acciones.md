# Pantallas y acciones

| Pantalla | Propósito | Acciones principales |
|---|---|---|
| Splash | Inicializa sesión y configuración | Dirige a acceso o comunidad. |
| Acceso | Inicio de sesión por correo | Iniciar sesión, ir a registro, recuperar contraseña. |
| Registro | Crea perfil de generador, receptor o mixto | Validar datos, privacidad y correo; no permite autoasignarse administrador. |
| Inicio / Comunidad | Resumen de la red y aportes del usuario | Ir a Crear/Buscar según rol, Mapa, Catálogo, Entidades y Guía botánica. |
| Mapa | Consulta publicaciones y hallazgos | Centrar, mover/zoom, filtros y abrir detalle; los filtros no deben ocultar el contenido. |
| Crear reporte | Asistente de tres pasos | Foto, ubicación, orientación, datos, revisión, publicar; borrador local, guardar/salir o descartar/cerrar. |
| Catálogo | Material disponible | Buscar, filtrar y abrir detalle; solicitar retiro si el rol lo permite. |
| Mi actividad | Publicaciones y solicitudes propias | Editar cuando esté permitido, revisar solicitudes, pases y comprobantes. |
| Perfil | Datos de la cuenta | Editar nombre/teléfono, exportar o eliminar cuenta, consentimiento de diagnósticos. |
| Ajustes | Apariencia y accesibilidad | Tema claro/oscuro, estación visual y tamaño de letra. |
| Recuperar contraseña | Restablecimiento por correo | Solicita correo; devuelve mensaje neutral para no revelar cuentas. |
| Directorio de entidades | Referencias locales en Suba | Ver ubicación y canal de contacto externo; no implica alianza ni disponibilidad garantizada. |
| Guía botánica | Catálogo y escáner | Buscar, filtrar con desplegables, foto para Pl@ntNet y orientación opcional. |
| Administración | Uso exclusivo de administrador verificado | Cola de feedback, usuarios, moderación y métricas cuando el backend de administración esté activo. |

## Botones críticos

- **Usar mi ubicación:** solicita precisión/granularidad; si falla se permite elegir punto manualmente dentro del área de atención.
- **Sugerir datos desde la evidencia:** analiza una foto JPG y muestra propuesta revisable. **Aplicar al formulario** solo copia datos al formulario actual.
- **Orientación para este reporte:** obtiene recomendaciones breves; no sustituye la revisión humana.
- **Guardar y salir:** conserva borrador de la cuenta actual. **Descartar y cerrar:** borra ese borrador. **Continuar editando:** mantiene el formulario abierto.
- **Publicar:** requiere foto, punto confirmado, título/condición y consentimiento; para oferta también autorización de entrega.
